# 外部材料与索取清单

> **背景（诊断项 D2）**：`docs/竞赛笔记.md` 里大量引用**不在本仓库**的材料——
> `AGENTS.md`、作者本机的 `D:\ISCC\...`、ROS 1 车的 `F1_yaofang.py`、裁判软件等。
> 新人读到这些地方会怀疑"是不是缺文件"。
>
> **本文的作用**：把"仓库外的依赖"集中列出来，说明**它是什么、为什么需要、怎么拿到**。
> 凡是标"需向作者索取"的，就是**仓库里确实没有、也无法从公开渠道拿到**的东西。

## 2. 没有它们会怎样（影响分级）

| 级别 | 材料 | 影响 |
|---|---|---|
| 🔴 **会卡住** | #6 厂商镜像、#7 OCR 运行时 | 没有镜像 → 新系统起不来；没有运行时 → 板二废 |
| 🟠 **会走弯路** | #1 `AGENTS.md`、#3 `F1_yaofang.py` | 能跑，但**理解不了某些历史结论的出处**；照着笔记做事不会错，只是"不知道为什么" |
| 🟡 **只影响追溯** | #2 目录、#8 复盘、#12 bags | 不影响跑车 |
| ⚪ **现场才有** | #4 裁判软件、#5 MD5 表 | 比赛当天必须 |

```
按 docs/外部材料与索取清单.md 的清单，想跟你要：

2. 厂商出厂镜像名/下载方式（EprobotV2.3-…）—— 影响重刷

【想要】
3. AGENTS.md（可以只给去掉密码的版本）

不方便给的跳过就行，我只想确认哪些是"确实没有"、哪些是我找错地方了。
```

## 5. 维护约定

- 新增"仓库外引用"时，**先加到本文件 §1**，再在正文里写"见 `外部材料与索取清单.md` #N"。
- 拿到新材料后，**从 §1 移走 → 放进 `cars/` 或 `docs/` → 在 §4 记一笔**。
- 涉及密码/密钥的材料（如 `AGENTS.md`），**永远只要"脱敏版"**（见 [`../SECRETS.md`](../SECRETS.md)）。
