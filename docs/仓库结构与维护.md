# 仓库结构与维护

> 给"以后要更新这个仓库"的人（含 AI）看。规则很简单：**`rootfs/` 镜像车上的绝对路径，`src/` 放需要编译的东西，`docs/` 放为什么。**

---

## 1. 目录约定

```
cars/car22/
  rootfs/            相对路径 == 车上绝对路径，可直接按路径覆盖
    opt/             /opt/...
    home/keyuan22/   /home/keyuan22/...
    etc/             /etc/...（只放本项目相关的文件，不是整份 /etc）
    usr/local/bin/   /usr/local/bin/...
  src/               需要 colcon build 的源码（不是成品）
    opt_eprobot_ws_src/    → /opt/eprobot_ws/src/
    relay_ws/mono8_relay/  → ~/relay_ws/src/mono8_relay/
```

**为什么这么排**：`rootfs/` 可以 `cp -a rootfs/. /` 一把铺（脚本里按路径备份），不用记"哪个文件该去哪"。
`src/` 单独放，是因为它们**必须在新车上重新编译**（架构相同但链接的库/路径不同），直接拷二进制会缺依赖。

---

## 2. 怎么从车上更新这个仓库（只读）

```bash
# 主机上（WSL / Linux），一条命令
bash tools/backup_car.sh --host 10.211.121.22 --user keyuan22 --out ~/car22-snapshot

# 它会 tar 流式打包（不在车上落任何文件），然后你 diff 一下再提交
diff -r ~/car22-snapshot/rootfs cars/car22/rootfs | head -50
```

**更新纪律**
1. **只读**：`tar czf -` 输出到本地，车上不写一个字节。
2. **先 diff 再覆盖**，别盲拷——车上可能有人手改过、没提交。
3. **二进制变了要记一笔**：`f1_mission_node` 换过版本就在 commit message 里写清（md5 前 8 位）。
4. 一次 commit 只做一件事（换二进制 / 改参数 / 补文档分开提交）。

## 3. 什么必须入库、什么不能入库

**必须入库**
- 所有 `.py` / `.launch.py` / `.yaml` / `.service` / `.sh` / `.xml`（BT）
- 任务层**二进制**（源码不存在，二进制是唯一产物）
- 语音 wav（77 个，约 9 MB）——`speech_manifest.json` 与文件名强绑定
- 板二模型（6.1 MB）与验收样图
- 相机 SDK（`/opt/oni2-orbbec`，2.8 MB）——公网已下不到（`dl.orbbec3d.com` 403）
- **STM32 下位机固件**（`cars/car22/firmware/chassis_mcu/`，两个 `.7z` + 原理图 + 协议表，约 24 MB）——MCU 重烧的唯一凭据
- **WSL 快捷指令**（`tools/wsl/`）——主机侧操作入口，含给 `.21` 用的 `iscc21`

**不能入库**
| 东西 | 原因 | 替代 |
|---|---|---|
| 任何密码 / key / `chrony.keys` / `iscc.conf` 真本 | 泄露 | `iscc.conf.example` |
| `board2_ocr/runtime_arm64`（276 MB） | 体积 | `requirements.txt` 重装；或从旧车整目录拷 |
| `cartographer` / `cartographer_ros`（9 MB） | 上游标准包 | `apt install ros-lyrical-cartographer*` |
| `/opt/ros/lyrical` | 太大 | apt |
| `*.bak_*`（车上几十个） | 噪音 | 真需要就单独开分支/发 release |
| `bags/` `evidence/` `*.jsonl` | 运行期数据 | — |

## 4. 提交规范

沿用车上仓库（`robot_ws/src`）的风格，**英文 + Conventional Commits**：

```
feat(car22): add mono8 relay source
fix(car22): correct A waypoint y 2.40 -> 2.50
docs: add 新车部署手册
chore: sync car22 rootfs from 10.211.121.22 (2026-11-13)
```

- **一次提交一个目的**
- 改二进制时：`chore(car22): update f1_mission_node (md5 4f9f0936)`
- 禁止 `git add -A` 之前不 `git status` 复核（本仓库 `.gitignore` 已挡住常见噪音）

## 5. 换车/换场地时的最小改动集

| 场景 | 要改的文件 |
|---|---|
| 换 IP | `rootfs/etc/netplan/{01-wlan0,50-cloud-init}.yaml`；主机 `iscc.conf` |
| 换裁判机 | `rootfs/.../config/pharmacy.yaml` 的 `judge_tcp.host` |
| 换场地/换车 | `rootfs/.../config/mission_waypoints.yaml`（全量重标） |
| 换热点 | `netplan` 的 `access-points` |
| 换相机（有 UVC 的型号） | 去掉 `openni2-camera`/`mono8-relay`，改 `competition.launch.py` 传 `start_camera:=true` + `video_device` |
| 换 IMU | `rootfs/etc/udev/rules.d/99-eprobot-h30.rules`（序列号）+ `yesense_config.yaml`（串口/波特率） |
| 换雷达 | `rootfs/etc/systemd/system/lslidar.service` + `usr/local/bin/lslidar-ctl` |
