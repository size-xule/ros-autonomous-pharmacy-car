## 3. 路径 C：要复现一辆车（1 天）

> 详细清单见 `docs/最小可复现清单.md`（待建）。这里是 30 秒版。

```
环境准备 → 依赖安装 → rootfs 铺设 → 编译 → 填配置 → 标航点 → 起车验收
   ↑ 新车有 ROS2 Lyrical    ↑ iscc     ↑ apply_to_car22.sh --build   ↑ 密码/裁判IP   ↑ 必做
```

**前 3 个命令**
```bash
git clone https://github.com/size-xule/ros-autonomous-pharmacy-car.git
bash install/apply_to_car22.sh --host <新车IP> --user <账号> --dry-run   # 先看
bash install/apply_to_car22.sh --host <新车IP> --user <账号> --yes       # 再写
```

**必须先知道的 3 件事**
1. 相机差异：Astra S 要 `openni2-camera + mono8-relay`；有 UVC 的（如 `.21`）**不要**这套。
2. 航点**必须重标**，坐标不能跨车使用（`board2` 两车差 0.72 m）。
3. `eprobot_base_cpp` 的源码不在仓库里，**`colcon build` 不要选它**。

## 4. 路径 D：想改任务逻辑（半天，但要知道边界）

### 4.1 能改的（安全区）

| 想改 | 改哪里 | 生效方式 | 风险 |
|---|---|---|---|
| 航点/朝向 | `rootfs/.../config/mission_waypoints.yaml` | `systemctl restart eprobot-nav` 或重跑 mission | 低（但要重标） |
| 进框限速 | `rootfs/home/keyuan22/eprobot_navigation/scripts/goal_speed_limit.py` | 重启 `eprobot-nav` | 低 |
| 到点判据 | `goal_checker_bridge.py` + `nav2_params.yaml` 的 `fine/coarse/yaw` | 同上 | 中（改狠了会到不了） |
| Nav2 全局/局部参数 | `nav2_params.yaml` | 同上 | 中（一次只改一个） |
| 板二后端（OCR/模板） | `competition.launch.py` 的 `board2_backend` | `systemctl restart eprobot-pharmacy` | 低 |
| 语音文案/语速 | `audio/competition/*.wav` + `speech_manifest.json` | 重启 `eprobot-pharmacy` | 低（文案要与 manifest 严格一致） |
| 底盘驱动参数 | `install/eprobot_base_cpp/.../base.yaml` | `systemctl restart eprobot-base` | 中（PID/轴距改了要实训） |
| 服务启停/环境变量 | `/etc/systemd/system/*.service` + `/etc/default/eprobot-pharmacy` | `daemon-reload` + restart | 中 |

### 4.2 改不了的（别浪费时间）

| 想改 | 为什么不行 | 唯一出路 |
|---|---|---|
| 任务流程（C→A→B 顺序、重试策略、播报时机） | `f1_mission_node` **只有二进制**，源码厂商未给 | 找厂商/队友要 `pharmacy_pkg` colcon 工程 |
| 二维码识别算法 | `pharmacy_qr_node` 同上 | 同上 |
| 裁判上报字段 | `judge_tcp_node` 同上 | 同上（协议格式见 [`§10.2`](竞赛笔记.md)） |
| C++ 驱动的实现细节 | `eprobot_base_cpp` 只有头文件 | 按 `src/.../eprobot_base/`（Python）重写 |

> **一条经验**：先问"这是参数还是逻辑"。**参数**改 YAML 就能救；**逻辑**就得有源码。

## 7. 三条通用建议

1. **先跑通再改**：任何改动前，确保"现状是能跑的"，否则你分不清是改坏了还是本来就坏。
2. **一次只改一个变量**：见 [`§13` 试错方法论](竞赛笔记.md)。
3. **改完立刻提交**：仓库按 `docs(编号): 说明` 的格式留痕，别攒。
