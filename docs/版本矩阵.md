## 5. 版本变更时的检查清单

改了任何一层，按这个顺序验：

```bash
# ① 二进制没被换
cd cars/car22/rootfs/opt/eprobot_ws/install/pharmacy_pkg/lib/pharmacy_pkg && bash verify.sh

# ② 依赖版本没漂
dpkg-query -W -f='${Package}=${Version}\n' ros-lyrical-ros-base ros-lyrical-nav2-bringup

# ③ 描述文件与现实一致
bash tools/selfcheck.sh

# ④ 实车六项验收
ros2 topic hz /odom                       # ~50 Hz
ros2 topic hz /scan                       # ~10 Hz
ros2 topic echo --once /imu/data          # 有四元数
ros2 topic echo --once --qos-reliability best_effort /battery_state | grep voltage   # ≥11 V
ros2 topic hz /camera/rgb/image_raw --qos-reliability best_effort                    # 7~10 Hz
journalctl -u eprobot-nav | grep 'Managed nodes are active'
```

**然后更新本文件**（§1 或 §3 加一行，§4 加遇到的坑）。
