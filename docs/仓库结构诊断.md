## 3. 命名风格现状

| 目录 | 现状 | 是否一致 |
|---|---|---|
| `docs/` | 4 篇全中文名，无编号 | ✅ 一致 |
| `cars/*/README.md` | 统一 `README.md` | ✅ |
| `tools/*/README.md` | wsl / host-iscc 有，probes **无** | ⚠️ 缺 |
| `rootfs/**/README.md` | 只有 `board2_ocr` 与 `eprobot_navigation` 自带（厂商或前届写的） | ⚠️ 覆盖不全 |

**结论**：`docs/` 命名风格已统一为中文名，**建议继续保持"中文名 + 必要前缀（`附录-` / `adr/NNNN-`）"**，不做 `NN-` 编号化——理由：现有交叉引用密度高，重命名收益（顺序感）用一个导读页即可覆盖。
