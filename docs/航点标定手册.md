# 航点标定手册

> **适用**：换车、换场地、换了相机/雷达安装位置、或发现"车能到但总差一点"。
> **核心事实**：`mission_waypoints.yaml` 里的坐标是"**这辆车 + 这块场地 + 这次停车姿态**"量出来的，
> **换任何一项都必须重标**。
>
> 已知证据：`.21` 和 `.22` 同一套代码，`board2` 点位差 **0.72 m**、`board1` 差 **10 cm**（见 [`../cars/car21/README.md`](../cars/car21/README.md) §2）。
> **照抄别人车的坐标 = 直接撞货架。**

---

## 0. 标定前必须知道的四件事

| # | 事实 | 依据 |
|---|---|---|
| 1 | 坐标在 **`map` 坐标系**，单位 m，yaw 是弧度（右正、逆时针为正） | `mission_waypoints.yaml` 注释 |
| 2 | 每点必须满足 **到墙/货架余量 > 车体半对角 0.186 m**（车体 0.30×0.22） | 笔记 §7.5 |
| 3 | `board1` / `board2` 是**识别点**，不是"路过点"——距离决定码在画面里的大小 | 笔记 §8 |
| 4 | 改完要 **重载 Nav2**，只改文件不重启不生效 | 笔记 §6.4 |

## 1. 准备（15 分钟）

| # | 做什么 | 命令 / 判据 |
|---|---|---|
| 1 | 车充满电 | `ros2 topic echo --once --qos-reliability best_effort /battery_state \| grep voltage` → ≥ **11.5 V** |
| 2 | 场地清空，货架按比赛位置摆好 | **这一步不做，标了也白标** |
| 3 | 起底盘 + 雷达 + 定位 | `iscc pre`（主机侧），等 `Managed nodes are active` |
| 4 | 打开 RViz | `iscc rviz2`（WSL 里）；确认激光贴墙、车模在地图正确位置 |
| 5 | 准备记录表 | 本文 §5 模板，打印或开个表格 |

> ⚠️ 标定全程车**需要动**（手动遥控或开点），场地必须清空、人站侧面。

## 2. 标定流程（一个点 5 分钟）

### 2.1 先对初始位姿（每次都做）

```bash
# 车推到起点（home = 地图原点，车头朝 +x）
# RViz → 工具栏 [2D Pose Estimate] → 在地图上点住原点、朝 +x 拖一下
ros2 topic echo --once --field pose.pose /amcl_pose     # 看 x/y/yaw 是否≈0
```

**判据**：`x`、`y` 在 ±0.05 m 内，`yaw` 在 ±0.05 rad 内。不满足就重对，别往下走。

### 2.2 开到目标点，读坐标

```bash
# 手动遥控（或写个临时 goal 让它自己开过去）
ros2 topic echo --once --field pose.pose /amcl_pose
```

输出长这样（节选）：
```
position: {x: 1.462, y: 1.849, z: 0.0}
orientation: {x: 0.0, y: 0.0, z: 0.7069, w: 0.7073}   ← 四元数，要转成 yaw
```

**yaw 换算法**（`z`/`w` 两分量即可，因为车只在平面动）：
```bash
python3 -c "import math;z=0.7069;w=0.7073;print(round(2*math.atan2(z,w),3))"
# → 1.571  (≈90°)
```

### 2.3 量余量（决定这个点能不能用）

用 RViz 的 **Costmap** 显示，打开 `global_costmap` 的膨胀层：

- 目标点必须落在**未被膨胀的白色区域**里；
- 目测点到最近障碍的距离，**必须 > 0.19 m**（0.186 + 2 cm 安全量）。

> 更稳的办法：把车停在该点，用卷尺量"车头/车侧到货架"的最小距离，记进表格。

### 2.4 写进 YAML

```yaml
nav_pharmacy:
  ros__parameters:
    waypoints:
      C: [1.47, 1.85, 1.5708]     # [x, y, yaw]
      A: [0.605, 2.50, 1.5708]
      B: [1.46, 2.88, 0.7854]
      '4': [-1.63, 0.762, -1.5708]
      '3': [-2.37, 1.41, -1.5708]
      '2': [-1.62, 1.84, -1.5708]
      '1': [-2.37, 2.41, -1.5708]
      home: [0.0, 0.0, 0.0]
      board2: [-1.62, 3.76, -3.1416]
      board1: [0.518, 0.0, 0.0]
      ac_transit: [1.49, 2.88, 0.7854]   # 可选，删掉则 C→A
```

**格式铁律**
1. 比赛航点必须是 **3 个有限值** `[x, y, yaw]`；`ac_transit` 允许只给 `[x, y]`（yaw 默认 0）。
2. 键名 **`'1'`…`'4'` 要加引号**（否则 YAML 解析成整数键，节点找不到）。
3. 不要留 `nan` / `inf` / 空值。

### 2.5 生效 + 校验

```bash
# 重载（只 restart nav，不用重启整车）
sudo systemctl restart eprobot-nav
# 等它就绪
journalctl -u eprobot-nav -f | grep -m1 'Managed nodes are active'
```

**校验命令**（复制即用，打印"当前位姿 vs 目标点"的偏差）：

```bash
python3 - /opt/eprobot_ws/install/pharmacy_pkg/share/pharmacy_pkg/config/mission_waypoints.yaml <<'PY'
import math, sys, yaml, rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseWithCovarianceStamped

WP = yaml.safe_load(open(sys.argv[1]))['nav_pharmacy']['ros__parameters']['waypoints']

class Probe(Node):
    def __init__(self):
        super().__init__('waypoint_probe')
        self.p = None
        self.create_subscription(PoseWithCovarianceStamped, '/amcl_pose', self.cb, 10)
    def cb(self, msg):
        self.p = msg.pose.pose

rclpy.init(); n = Probe()
while n.p is None and rclpy.ok():
    rclpy.spin_once(n, timeout_sec=0.5)

p = n.p
# yaw from quaternion (planar)
yaw = 2 * math.atan2(p.orientation.z, p.orientation.w)
print(f"\n当前位姿: x={p.position.x:+.3f}  y={p.position.y:+.3f}  yaw={yaw:+.3f} rad ({math.degrees(yaw):+.1f}°)\n")
print(f"{'航点':<12}{'目标 x,y,yaw':<28}{'距离(m)':>9}{'角度差(°)':>11}  判定")
print("-" * 78)
for name, v in WP.items():
    if not isinstance(v, list) or len(v) < 2:
        continue
    tx, ty = float(v[0]), float(v[1])
    tyaw = float(v[2]) if len(v) > 2 else 0.0
    d = math.hypot(tx - p.position.x, ty - p.position.y)
    dyaw = math.degrees(math.atan2(math.sin(tyaw - yaw), math.cos(tyaw - yaw)))
    ok = "✅ 已到" if (d <= 0.20 and abs(dyaw) <= 10) else ""
    print(f"{name:<12}{f'{tx:+.3f},{ty:+.3f},{tyaw:+.3f}':<28}{d:>9.3f}{dyaw:>11.1f}  {ok}")
n.destroy_node(); rclpy.shutdown()
PY
```

**判据**：
- 车停在某航点上时，该行 `距离 ≤ 0.20 m`、`角度差 ≤ 10°` → 这点标定合格；
- 若所有点都系统性偏同一个方向 → **先怀疑初始位姿没对**（回 §2.1），不要改坐标。

## 3. 特殊点位的额外要求

| 点 | 额外要求 | 为什么 |
|---|---|---|
| `home` | 必须是地图原点、车头 +x | `set_initial_pose` 与回原点逻辑都依赖它 |
| `board1` | 二维码在画面中 **≥ 80 px**（≥55 px 才能解） | 太小解不出，`QR scan: candidates=0` |
| `board2` | 文字牌占画面 1/3 以上；**不要贴太近**（过曝） | OCR 认错数字会比认不出更糟 |
| `C` / `A`（取样窗口） | 必须**整车进框**，余量 > 0.19 m | 部分出框每次扣 1 分 |
| `B`（45° 转向点） | 右后侧余量要 > 0.30 m | 45° 收尾会右甩 ~0.14 m |
| `ac_transit` | 与 `B` 几乎同点，**不要删**（除非确定要跳过 AC 任务） | 删了任务变成 C→A，实测过 |

## 4. 常见错误（按出现频率）

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了 yaml 没生效 | 没 `restart eprobot-nav` | `sudo systemctl restart eprobot-nav` |
| 车到点后原地打转 | 该点 yaw 与到达方向差太大，阿克曼没法原地转 | 把 yaw 调成"来向的角度"或改用 `ac_transit` 过渡 |
| `Start occupied` / `collision ahead` | 点太靠墙（余量 < 0.186 m） | 往通道中心挪 5~10 cm，重标 |
| 所有点都偏 0.3~0.5 m | 初始位姿没对 / 地图与实地不符 | 重对 2D Pose Estimate；确认地图是当前场地 |
| `board2` 识别率突然变差 | 停车位置变了（相机视野边角畸变大） | 重新量 `board2` 点，宁可退后 10 cm |
| 两车坐标混用 | 照抄了另一台车的 yaml | 见本文开头：差 0.72 m |
