# 依赖清单

> 目标：**在一台全新的 Ubuntu 26.04 (aarch64) 上，装出与原车一致的依赖版本。**
> 数据来源：2026-11-13 在 `car22`（`10.211.121.22`）上 `dpkg-query` 实测，不是抄包名。
> 版本号带 `resolute.<日期>` 后缀的是 **ROS 2 官方 apt 源**的构建号，必须走同一个源才能完全一致。

---

## 0. 先确认三件事

```bash
uname -m                     # 必须 aarch64
. /etc/os-release; echo $VERSION_CODENAME   # 必须 resolute（Ubuntu 26.04）
ls -d /opt/ros/lyrical       # ROS 2 Lyrical 已装
```

> ⚠️ **x86 上装出来的东西不能拷到车上**（onnxruntime / OpenCV 的 `.so` 架构不同，会 `Illegal instruction`）。
> 要么直接在车上装，要么在另一台 arm64 上装。

## 1. apt 源（原车实测）

```
# Ubuntu 本体（原车同时留了官方源和阿里云源）
deb http://archive.ubuntu.com/ubuntu resolute main universe restricted multiverse
deb http://archive.ubuntu.com/ubuntu resolute-updates main universe restricted multiverse
deb http://archive.ubuntu.com/ubuntu resolute-backports main universe restricted multiverse
deb http://security.ubuntu.com/ubuntu resolute-security main universe restricted multiverse

# ROS 2（官方 + 阿里云镜像，两份都配了，apt 会择一）
deb [arch=arm64 signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu resolute main
deb [arch=arm64 signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] https://mirrors.aliyun.com/ros2/ubuntu resolute main
```

**国内网络建议只留阿里云那两条**（官方源在车上实测很慢，装 129 个包要几小时）。

## 2. 安装顺序（照抄即可）

```bash
# ① ROS 2 apt 源（若镜像里还没配）
sudo apt-get update && sudo apt-get install -y curl gnupg lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list

# ② ROS 2 本体
sudo apt-get update
sudo apt-get install -y ros-lyrical-ros-base

# ③ 本项目实际用到的 ROS 功能包（版本见 §3）
sudo apt-get install -y \
  ros-lyrical-nav2-bringup ros-lyrical-nav2-amcl \
  ros-lyrical-nav2-mppi-controller ros-lyrical-nav2-smac-planner \
  ros-lyrical-nav2-bt-navigator \
  ros-lyrical-image-transport ros-lyrical-cv-bridge \
  ros-lyrical-tf2-ros ros-lyrical-diagnostic-updater \
  ros-lyrical-robot-state-publisher ros-lyrical-xacro \
  ros-lyrical-slam-toolbox ros-lyrical-cartographer-ros-msgs

# ④ 系统库（编译 src/ 与跑相机用）
sudo apt-get install -y \
  python3-numpy python3-opencv \
  libboost-thread1.90.0 libudev1 libgomp1 \
  build-essential cmake python3-pip python3-colcon-common-extensions
```

## 5. 怎么导出本机的完整快照（换车前必做）

```bash
# ① 所有已装包的精确版本（约 1500 行，作为"原车指纹"存档）
dpkg-query -W -f='${Package}=${Version}\n' > ~/dpkg-snapshot.txt

# ② 只导 ROS 包（更常用）
dpkg -l | awk '/^ii  ros-lyrical/ {print $2"="$3}' > ~/ros-packages.txt

# ③ 导出 apt 源
grep -rhE '^(deb|URIs|Suites|Components)' /etc/apt/sources.list /etc/apt/sources.list.d/ \
  > ~/apt-sources.txt

# ④ 系统 Python 版本
python3 -V >> ~/dpkg-snapshot.txt
```

**在另一个系统上比对差异**（只列版本不同的）：
```bash
diff <(sort ~/ros-packages.txt) <(dpkg -l | awk '/^ii  ros-lyrical/ {print $2"="$3}' | sort) | head -50
```

## 6. 验收：怎么算"装对了"

| # | 检查 | 命令 | 期望 |
|---|---|---|---|
| 1 | ROS 2 能 source | `source /opt/ros/lyrical/setup.bash && ros2 --version` | 有输出 |
| 2 | Nav2 组件在 | `ros2 pkg list \| grep -c nav2_` | ≥ 10 |
| 3 | MPPI 有 | `ros2 pkg list \| grep nav2_mppi_controller` | 有 |
| 4 | Smac 有 | `ros2 pkg list \| grep nav2_smac_planner` | 有 |
| 5 | cv_bridge 有 | `ros2 pkg list \| grep cv_bridge` | 有 |
| 6 | 编译 `src/` 不报错 | 见 [`../cars/car22/src/README.md`](../cars/car22/src/README.md) §2 | `colcon build` 成功 |
| 7 | OCR 运行时能 import | 见 [`runtime/README.md`](../cars/car22/rootfs/home/keyuan22/board2_ocr/runtime/README.md) §3.1 | 版本打印正确 |
| 8 | 雷达能开 | `ls /dev/EPRobot_laser` | 存在（udev 规则见 [`udev/rules.d/README.md`](../cars/car22/rootfs/etc/udev/rules.d/README.md)） |

> 第 6 项**不要**把 `eprobot_base_cpp` 加进 `--packages-select`——那个包没有源码（只有头文件 + 二进制）。
