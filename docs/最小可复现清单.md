# 最小可复现清单

> **目标**：拿一台**同型号空车**，只照这份清单，跑到和 `car22` 一样（能跑完整圈）。
> **用法**：从上到下打勾。每项都有"怎么验"，**验不过不要往下走**——越往后越贵。
>
> 预计总耗时：**1 天**（其中 2 小时在等 apt、1 小时在现场标航点）。
> 前置：这台车已刷好厂商镜像（有 `/opt/ros/lyrical` 与 `/opt/eprobot_ws`）；若没有，先找厂商要镜像。

---

## 阶段 0 环境准备（30 min）

- [ ] **0.1 能连上新车**
      ```bash
      ping <新车IP>
      ssh <账号>@<新车IP> 'hostname; . /etc/os-release; echo $PRETTY_NAME; uname -m'
      ```
      验：打印 `Ubuntu 26.04*` + `aarch64`。
      ⚠️ 新车若还是默认 IP/账号，先在**车本机**（键盘/HDMI）改好，别指望远程能连上。

- [ ] **0.2 确认 IP / 账号不会和 `.22` 撞**
      验：`<新车IP>` ≠ `10.211.121.22`；`ROS_DOMAIN_ID` 计划用 **2**（两车同网时）。
      见 [`竞赛笔记.md` §18.4](竞赛笔记.md)。

- [ ] **0.3 主机侧有 `iscc` 与 `sshpass`**
      ```bash
      iscc version     # 能打印 robot 行即可，先不用连对
      ```
      验：装法见 [`../tools/host-iscc/README.md`](../tools/host-iscc/README.md)。

- [ ] **0.4 拿到仓库**
      ```bash
      git clone https://github.com/size-xule/ros-autonomous-pharmacy-car.git
      cd ros-autonomous-pharmacy-car
      bash tools/selfcheck.sh --quiet     # 仓库自身是否完整
      ```
      验：`FAIL 0`。

## 阶段 1 依赖安装（2 h，含等待）

- [ ] **1.1 换 apt 源为国内镜像**（否则 334 个包装不完）
      见 [`依赖清单.md` §1](依赖清单.md)（阿里云 `resolute` + `mirrors.aliyun.com/ros2`）。

- [ ] **1.2 装 ROS 2 与功能包**
      ```bash
      sudo apt-get update
      sudo apt-get install -y ros-lyrical-ros-base \
        ros-lyrical-nav2-bringup ros-lyrical-nav2-amcl \
        ros-lyrical-nav2-mppi-controller ros-lyrical-nav2-smac-planner \
        ros-lyrical-nav2-bt-navigator \
        ros-lyrical-image-transport ros-lyrical-cv-bridge \
        ros-lyrical-tf2-ros ros-lyrical-diagnostic-updater \
        ros-lyrical-robot-state-publisher ros-lyrical-xacro \
        ros-lyrical-slam-toolbox ros-lyrical-cartographer-ros-msgs \
        python3-numpy python3-opencv libboost-thread1.90.0 libudev1 libgomp1 \
        build-essential cmake python3-pip python3-colcon-common-extensions
      ```
      验：`ros2 pkg list | grep -c nav2_` ≥ 10。

- [ ] **1.3 装标定工具（可选，只在要标相机时装）**
      `sudo apt install -y ros-lyrical-camera-calibration`

- [ ] **1.4 主机侧依赖**
      `sudo apt install -y sshpass`（只在主机 WSL 里）。

## 阶段 2 rootfs 铺设（20 min）

- [ ] **2.1 先 dry-run 看要改什么**
      ```bash
      bash install/apply_to_car22.sh --host <新车IP> --user <账号> --dry-run
      ```
      验：打印清单，**没有写任何东西**。

- [ ] **2.2 真铺**
      ```bash
      bash install/apply_to_car22.sh --host <新车IP> --user <账号> --yes
      ```
      验：结束时会打印"备份到 `~/.backup_<时间戳>/`"与"手动检查清单"。

- [ ] **2.3 建两个软链**（脚本会做，核对即可）
      ```bash
      cd /opt/oni2-orbbec && ls -l libOpenNI2.so.0 libOpenNI2.so.0.0
      ```
      验：两个都指向 `libOpenNI2.so`。

- [ ] **2.4 改 udev 的 IMU 序列号**（**换车必改**）
      见 [`../cars/car22/rootfs/etc/udev/rules.d/README.md` §1.2](../cars/car22/rootfs/etc/udev/rules.d/README.md)。
      验：`ls -l /dev/EPRobot_imu` 存在。

## 阶段 3 编译（20 min）

- [ ] **3.1 编 `src/`**
      ```bash
      cp -a cars/car22/src/opt_eprobot_ws_src/* /opt/eprobot_ws/src/
      cd /opt/eprobot_ws && source /opt/ros/lyrical/setup.bash
      colcon build --symlink-install --packages-select \
        serial_ros2 yesense_interface yesense_std_ros2 lslidar_ros2
      ```
      验：`colcon build` 结束无 `Failed`。
      ⚠️ **不要选 `eprobot_base_cpp`**（无源码）。见 [`../cars/car22/src/README.md`](../cars/car22/src/README.md)。

- [ ] **3.2 编灰度中继**
      ```bash
      mkdir -p ~/relay_ws/src && cp -a cars/car22/src/relay_ws/mono8_relay ~/relay_ws/src/
      cd ~/relay_ws && source /opt/ros/lyrical/setup.bash && colcon build --packages-select mono8_relay
      ```
      验：`ls ~/relay_ws/install/mono8_relay/lib/mono8_relay/` 有可执行文件。

- [ ] **3.3 装 OCR 运行时（276 MB）**
      三种办法见 [`../cars/car22/rootfs/home/keyuan22/board2_ocr/runtime/README.md`](../cars/car22/rootfs/home/keyuan22/board2_ocr/runtime/README.md) §4。
      验：`bash board2_ocr/selftest_arm64.sh` 输出 `READY` + 13 行 `FREE/BUSY_n`（≥12 正确）。

## 阶段 4 配置填写（15 min）

- [ ] **4.1 WiFi / 密码**（会静默失效的那种）
      - `cars/car22/rootfs/etc/netplan/01-wlan0.yaml` 与 `50-cloud-init.yaml`：SSID + `WIFI_PASSWORD_HERE`
      - 主机 `~/.config/iscc/iscc.conf`：`ROBOT_PASS`
      见 [`SECRETS.md`](../SECRETS.md) §1。验：`iscc version` 能连上。

- [ ] **4.2 裁判机地址**
      `.../config/pharmacy.yaml` 的 `judge_tcp.host` 改成**现场裁判机 IP**（仓库里是 `.38`，常年不对）。
      验：车上 `nc -zv <裁判IP> 8888` → succeeded。

- [ ] **4.3 `ROS_DOMAIN_ID` 对齐**
      若新车用 2：要改 **15 个 unit** + `iscc.conf` + 主机环境变量。
      验：`grep -c ROS_DOMAIN_ID=2 /etc/systemd/system/*.service` = 15。

- [ ] **4.4 `JUDGE_CAR_ID`**
      改 `/etc/default/eprobot-pharmacy`（**不是** unit 里那个 24）。
      验：`systemctl show eprobot-pharmacy -p Environment` 能看到 25。

## 阶段 5 起车验证（30 min）

- [ ] **5.1 冷启动**
      ```bash
      iscc kill && iscc pre
      ```
      验：六项全过 ↓

- [ ] **5.2 六项验收**（缺一不可）
      | 项 | 命令 | 期望 |
      |---|---|---|
      | 里程 | `ros2 topic hz /odom` | ~50 Hz |
      | 雷达 | `ros2 topic hz /scan` | ~10 Hz |
      | IMU | `ros2 topic echo --once /imu/data` | 有四元数 |
      | 电池 | `ros2 topic echo --once --qos-reliability best_effort /battery_state \| grep voltage` | ≥ 11.5 V |
      | 图像 | `ros2 topic hz /camera/rgb/image_raw --qos-reliability best_effort` | 7~10 Hz |
      | Nav2 | `journalctl -u eprobot-nav \| grep 'Managed nodes are active'` | 有 |

- [ ] **5.3 看得到、定位对**
      `iscc gray`（有清晰画面）→ `iscc rviz2`（激光贴墙、车在地图正确位置）。
      验：车与墙误差 < 10 cm。

## 阶段 6 航点标定（1 h，**必做，不能跳过**）

- [ ] **6.1 按手册标 11 个点**
      见 [`航点标定手册.md`](航点标定手册.md)。每个点记"坐标 + 实测余量"。

- [ ] **6.2 校验偏差**
      跑手册 §2.5 的脚本，逐点看 `距离 ≤ 0.20 m`、`角度差 ≤ 10°`。

- [ ] **6.3 提交**
      ```bash
      git add cars/car22/rootfs/opt/eprobot_ws/install/pharmacy_pkg/share/pharmacy_pkg/config/mission_waypoints.yaml
      git commit -m "tune(car22): 新车航点标定"
      ```

## 阶段 7 完整跑一圈（30 min）

- [ ] **7.1 清场 + 摆货架**（与比赛一致）

- [ ] **7.2 发车**
      ```bash
      iscc start
      ```
      验：跑完一圈，`mission.jsonl` 里有 `delivery_completed`。

- [ ] **7.3 板二验证**
      板二牌面应被识别为 `FREE` 或 `BUSY_n`（不是 `UNKNOWN`）。
      验：`journalctl -u eprobot-pharmacy | grep -i board2`。

- [ ] **7.4 裁判连通**
      验：裁判软件上能看到车、有速度/位置/任务。

- [ ] **7.5 收尾**
      ```bash
      iscc stop && iscc kill
      bash tools/gen_manifest.sh && git status    # 把新车上的改动同步回仓库
      ```
