## 0. 三分钟决定你怎么读

| 你的情况 | 走哪条 | 预计 |
|---|---|---|
| 完全不懂 ROS，只想搞明白这车怎么跑 | 路径 A：①→②→⑦ | 1.5 天 |
| 要接手维护，得能独立发车、排障 | 路径 B：①→②→③→④→⑤→⑥→⑧ | 4 天 |
| 只想改任务逻辑/调参 | 路径 C：①→⑦→⑥→⑧ | 1 天 |
| 赶着比赛，只有 3 小时 | 只读 §0 + §12 + §14（发车清单 + 踩坑总表） | 3 小时 |

> **一句忠告**：这份笔记里的每条"坑"都对应一次真实翻车。**先读完 §14 再动手**，能省你半天。

## 4. 这份笔记的边界（先知道，免得踩空）

1. **任务层（`pharmacy_pkg`）没有源码**，只有二进制。§7 讲的是"从事件流反推出来的行为"，不是读代码读出来的——**能改的只有 YAML / 限速 / Nav2 / unit**。
2. **ROS 1 那一章（§5）是历史对照**，源码不在本仓库，读者不用试图去跑。
3. 笔记里的 `D:\ISCC\...`、`AGENTS.md`、`F1_yaofang.py` 等**不在本仓库**，清单见 [`外部材料与索取清单.md`](外部材料与索取清单.md)。
4. 所有"⚠️ 未确认"都是作者没有实车验证的推断，**别当事实背**。
